# Security Policy

This repository is a **Da Hood Roblox Script** toolkit intended for
educational and personal use. Use at your own risk — automated scripting
against Roblox may result in account bans.

## Supported versions

| Version | Supported |
| ------- | --------- |
| 1.4.x   | yes       |
| 1.3.x   | security fixes only |
| < 1.3   | no        |

## Reporting a vulnerability

Please **do not** open public issues for security problems.

Email: security@dahood-scripts.invalid (PGP key in `docs/security.asc`).

Include:
- affected file / plugin
- reproduction steps
- Python + Roblox versions

We aim to respond within 72 hours.

## Out of scope

- Executor-side vulnerabilities (report upstream to the executor author)
- Roblox anti-cheat bypass reports — those are not our code
